Minesweeper / FIELD NOTES
Windows 64-bit向けマインスイーパー

【起動】
ZIPを右クリックして「すべて展開」し、展開先のMinesweeper.exeを起動します。
Unity EditorやUnity Hubのインストールは不要です。
exeとデータフォルダー・DLLはまとめて同じ場所に置いてください。
ZIPを開いたままexeだけを実行せず、すべてのファイルを展開してください。

【操作】
左クリック: マスを開く
右クリック: 旗を立てる / 外す
数字をダブルクリック / 中クリック: 周囲の旗が数字と同数なら一括開放
矢印キー: 選択マスの移動
Enter / Space: 選択マスを開く / 一括開放
F: 旗の切り替え
R: 新しい盤面
Esc: 遊び方の表示 / 非表示

初級: 9×9・地雷10個、中級: 16×16・40個、上級: 30×16・99個。
地雷以外のすべてのマスを開くとクリアです。
初手と周囲8マスは安全ですが、必ず推測なしで解けるとは限りません。
旗の位置を間違えると、一括開放で地雷を踏む場合があります。

【記録】
難易度とベストタイムは、このPCのWindowsユーザーごとに保存します。
途中の盤面は保存しません。遊び方の表示中と別ウィンドウ操作中はタイマーを停止します。

【配布ファイル】
build-info.txt: ゲームとUnityのバージョン、ビルド日時
SHA256SUMS.txt: 同梱ファイルのSHA-256一覧（この一覧自身を除く）

再頒布する場合も、ZIP内のファイルを省略せずまとめてください。
